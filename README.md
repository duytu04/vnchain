 A Layer 1 blockchain built with Cosmos SDK v0.47.3 for digital identity and public administration.

 ## Prerequisites
 - Go 1.21.11
 - Ignite CLI v0.27.1-dev
 - Docker Desktop v28.1.1
 - Git 2.48.1

 ## Setup
 1. Clone the repository: `git clone https://github.com/duytu04/vnchain.git`
 2. Build: `ignite chain build`
 3. Run: `ignite chain serve`

 ## Endpoints
 - RPC: `http://localhost:26657`
 - REST: `http://localhost:1317`
